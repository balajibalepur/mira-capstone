## 2. Anchor A — as-of date for status reporting

- Latest due date among Done tasks: `2026-04-18`
- Earliest due date among not-Done tasks: `2026-04-21` (T006)
- **as_of := 2026-04-21 (Tuesday)**

Rationale: the only date at which the board is self-consistent. Any later and the
driver task would be overdue while still marked In Progress; any earlier and the
Done tasks could not yet have completed. No real-world 'today' is introduced.

## 3. Anchor B — project start date

`project_timeline.csv` uses week numbers; `sample_task_board.csv` uses dates. The
join between them is a start date, found by constraint satisfaction over Mondays:

| Constraint | Requirement |
|---|---|
| 1 | Sprint 1 (Planning) due dates fall inside timeline Phase 1, weeks 1–2 |
| 2 | Sprint 2 (Analysis) due dates fall inside timeline Phase 2, weeks 3–4 |

Candidate Mondays tested: 8. Satisfying both constraints: 1 — 2026-03-30.

- **project_start := 2026-03-30 (Monday)**
- as_of 2026-04-21 therefore falls in **week 4**
